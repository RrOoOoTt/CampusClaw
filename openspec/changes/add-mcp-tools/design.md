# 设计

技术栈不变；独立mcp-server使用Go标准库，Compose内网运行，协议固定2025-03-26 JSON-RPC HTTP子集。API作宿主，不将用户Bearer、模型密钥或MCP凭据交叉复用。

登记只存凭据环境变量名；连接初始化、通知、分页发现完成后事务替换工具缓存。Skill保存验证本班已连接工具；执行前再次校验。主进程互斥锁串行登记与调用，适用于单API部署。

模型先做有上限的非流式工具决策，宿主验证、审计、执行、过滤，追加assistant/tool消息，达到停止条件后做最终流式回答。工具结果另附user数据摘要，不提升为system指令。请求记录无HTTP凭据头，限会话本人。

新增mcp_servers/mcp_tools/mcp_calls/llm_traces表、私有session_id与消息tool_calls字段，扩大Skill工具引用字段。原角色、绑定、上传、索引、历史数据保留。浏览器通过Nginx /api使用，独立MCP不暴露宿主端口。

失败行为：连接失败清空缓存并标记disconnected；断开/跨班/未发现/非法参数拒绝执行；审计失败不执行；工具错误丢弃不可信结果；模型决策失败尝试用原知识库回答。LLM本身不可用时保留原流式错误处理。
