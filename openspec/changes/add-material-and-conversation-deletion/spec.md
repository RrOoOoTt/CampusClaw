# Requirements
- 教师可删除本班资料，学生返回403，其他班级或不存在资料返回404，未登录返回401。
- MySQL资料、正文、切片级联删除；同一事务写入持久化清理任务。Qdrant按班级和资料双条件删除向量，并删除原文件。依赖失败时返回cleanup_pending，后台每30秒重试，重启后继续。数据库二次校验使残留向量不能被检索或下载。
- 资料索引与删除串行化，过期回填必须再次验证资料存在。采用单API进程部署。
- 历史回答与引用快照保留；资料删除后打开原材料返回404。已经开始的回答可能引用删除前检索到的内容，删除不会追溯修改历史。
- 用户仅可删除自己且属于当前班级的会话；教师也不能删除别人的会话。消息随会话级联删除。
- 生成中的会话返回409；删除与生成使用数据库行锁/条件更新避免并发冲突。停止生成后等待会话释放，再删除。
- DELETE请求执行同源校验。UI确认删除并更新列表、清空已删除的当前会话。
- 保留DeepSeek修复：对官方api.deepseek.com设置thinking disabled，输出上限2048；其他提供商不附加此参数。
