# Add a streaming learning assistant

## Why
第 5 课概述要求将第 4 课的本班检索接入一个连续追问的解题助手。一次回答须结合教师保存的角色提示词、解题引导技能、本班证据，并按会话保存、通过 SSE 返回。

## What changes
- 按班保存教师角色提示词与解题引导开关，保存后从下一轮生效；学生只读。
- 新增个人会话和消息历史，用户与班级双重限定；角色、班级、历史只从服务端读取。
- 服务端执行身份 → 配置快照 → 技能 → 本班混合检索 → 流式回答 → 保存；回答提供标题、切片、字符位置和原材料入口。
- 开启技能提供思路与提示，关闭允许直接回答；无证据说明资料中未找到，不编造出处。
- 主界面改为学习助手，材料页用于浏览、上传和重建；保留旧接口供第 4 课验收兼容。
- Bearer 认证和现有数据卷继续使用；增加 3 张表、SSE 网关能力和验收脚本。

## Non-goals
作业提交、批改、错题讲解、异步任务队列、关怀式对话、不在本课范围的另外两项技能、任意外部工具调用。

## Evidence and limits
仅收到本课概述这一份讲义，以上依据该页明确范围实现。默认网关是确定性演示 fixture，真实解题需接入支持 OpenAI-compatible Chat Completions SSE 的模型；不能把模拟回答当作模型能力评测。
